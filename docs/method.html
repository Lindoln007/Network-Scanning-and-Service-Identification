Build a network that can't escape, then survey it.

Four steps, each one a real command with its real output. The terminals below replay what was run on 18 November 2026.

§ 01 Topology

The lab network

One Python script, lab/lab_services.py, starts three hosts on the loopback range. Loopback traffic never leaves the computer, so the lab is isolated by design: no VMs and no risk to any real network.

  • 8080/tcpApache admin panel
i

How the lab services work. Each lab service answers connections with the banner the real software sends (for example 220 (vsFTPd 2.3.4)), and the web servers answer real HTTP requests. Nmap's version detection reads these banners, the same way it fingerprints a production server. The software versions are emulated, but the scan, the traffic and the results are all real.

The scans also found ports 135 and 445 (Windows RPC and SMB) on every lab address. These belong to the Windows host itself, which listens on all interfaces. It is a real finding, covered on the next page.

§ 02 Procedure

Four phases

Host discovery

Sweep 50 addresses for a handful of common ports. On loopback every address "answers a ping", so -Pn with --open is used instead: a host counts as live only if it has an open port.

Result: 3 live hosts. The quick sweep missed some ports (21 and 8080), which is why the full port scan in phase 3 matters.

01_host_discovery.txtraw ↗
nmap -sT -Pn -p 21-25,80,8080 --open 127.0.10.1-50

Port scan

A full TCP connect scan of ports 1–1024 plus 3306 and 8080 on each live host. -sT completes the TCP handshake, so it needs no raw-packet privileges. -T5 keeps it fast on a local link.

Closed ports show as filtered because Windows drops, rather than resets, connections to unused loopback ports.

Service & version detection

-sV probes each open port and matches the replies against Nmap's database of service fingerprints. -sC runs the default NSE scripts, which collected HTTP headers, page titles and SMB security mode.

This step turns "port 21 is open" into "vsftpd 2.3.4 is running", and that is where the risk becomes visible.

§ 03 Reference

Flags used

-sT
TCP connect scan: completes the full handshake and needs no admin rights
-Pn
Skip ping discovery and treat every target as up
--open
Show only hosts and ports that are open
-p
Choose which ports to scan
-T5
Fastest timing template, safe on a local link
-sV
Probe services to work out the software and version
-sC
Run the default, safe NSE scripts
-oN / -oX
Save normal and XML output as evidence
