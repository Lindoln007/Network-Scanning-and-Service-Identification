§ 01 Brief

The task

The brief: use Nmap to scan an isolated laboratory network and identify active hosts, open ports and running services, then report the services found with security recommendations.

The lab runs entirely inside one computer on the private loopback range 127.0.10.0/24, so no packet ever reaches a real network. Three machines were set up to look like a typical small office: a web server, an old file and mail server, and an admin workstation. Each one runs the services, and announces the software versions, you would expect to find on that kind of machine.

§ 02 Headline

What needs fixing first

  1. Remove vsftpd 2.3.4 on 127.0.10.20:21This exact version shipped with a backdoor (CVE-2011-2523) that gives a root shell. Replace it with SFTP.
    High
  2. Disable Telnet on 127.0.10.20:23Logins and passwords cross the network in plain text. Use SSH.
    High
  3. Patch outdated OpenSSH 7.4 and Apache 2.4.29Both are years old with published CVEs, and Apache announces its exact version to anyone who asks.
    Medium
  4. Lock the admin panel on :8080 and SMB on :445 behind the firewallManagement services should only be reachable from an admin network or VPN.
    Medium
